Dinamica Generale develops cloud and mobile software for precision agriculture. Our applications connect weighing systems and near-infrared (NIR) sensors to help farmers manage livestock feeding and field operations.

## Software

- [DTM](https://www.dinamicagenerale.com/product/dtm-software/) helps livestock teams manage feed rations and track feeding performance.
- [FIELD trace](https://www.dinamicagenerale.com/product/field-trace/) collects and maps field data from connected NIR sensors and weighing equipment.
